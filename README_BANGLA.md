# সেটআপ — পাঁচটি ধাপ

## 🔹 ধাপ ১ — SQL রান করুন (২ মিনিট)

1. Supabase Dashboard খুলুন
2. বাম পাশে **SQL Editor** → **New query**
3. `automation_migration.sql` ফাইলের পুরো লেখা কপি করে পেস্ট করুন
4. **Run** চাপুন → "Success" দেখালেই শেষ

> ✅ সম্পূর্ণ নিরাপদ — পুরনো ডাটা মুছবে না। দুইবার রান করলেও সমস্যা নেই।

---

## 🔑 ধাপ ২ — Key স্থায়ীভাবে বসান (সবচেয়ে জরুরি)

**কোথায় পাবেন:** Supabase Dashboard → **Settings** → **API**
- `Project URL` কপি করুন
- `anon public` key কপি করুন

**এরপর:** `config.js` ফাইলটা Notepad / VS Code দিয়ে খুলুন। একদম উপরে এই দুই লাইন পাবেন:

```js
var SUPABASE_URL = 'https://YOUR-PROJECT-ID.supabase.co';
var SUPABASE_ANON_KEY = 'YOUR-ANON-PUBLIC-KEY-HERE';
```

এখানে আপনার আসল মান বসান — যেমন:

```js
var SUPABASE_URL = 'https://abcdefgh.supabase.co';
var SUPABASE_ANON_KEY = 'eyJhbGciOiJIUzI1NiIsInR5cCI6...';
```

উদ্ধৃতি চিহ্ন `'...'` রাখুন, শেষে `;` রাখুন। সেভ করুন।

✅ **এরপর আর কখনো Connect স্ক্রিন আসবে না — অ্যাপ খুললেই সরাসরি লগইন পেজ।**

> 🔒 **নিরাপত্তা:** anon key ফ্রন্টএন্ডে রাখা সম্পূর্ণ নিরাপদ — Supabase নিজেই এটা public বলে। আসল সুরক্ষা RLS দেয়, যা আপনার সিস্টেমে চালু আছে। শুধু `service_role` key কখনো ফ্রন্টএন্ডে দেবেন না।

## 📁 ধাপ ৩ — সব ফাইল আপলোড করুন

পুরনো ফাইলগুলো মুছে এই ৪টা ফাইল একই ফোল্ডারে রাখুন:

```

```

কোনো সার্ভার/build লাগবে না — Netlify, Vercel, GitHub Pages, বা সাধারণ cPanel হোস্টিং সবজায়গায় চলবে।

## ⚙️ ধাপ ৪ — লগইন করে সেটিংস দিন

1. সাইট খুলুন → সরাসরি **লগইন পেজ** আসবে
2. Email + Password দিয়ে লগইন করুন
3. সাইডবারে **Automation** মেনু → এইগুলো পূরণ করে Save:
   - দোকানের নাম ও ফোন
   - **Owner WhatsApp** — এই নাম্বারে রিপোর্ট আসবে
   - প্রতি ১০০ টাকায় কত পয়েন্ট (ডিফল্ট ১)

---

## 📷 ধাপ ৫ — বারকোড সেটআপ (ঐচ্ছিক)

1. **Products** পেজে যান → পণ্য Edit করুন
2. **Barcode** ঘরে কার্সর রাখেন → পণ্যের বারকোড স্ক্যান করুন (নিজেই লিখে যাবে) → Save
3. এরপর POS পেজে শুধু স্ক্যান করলেই পণ্য কার্টে চলে আসবে

> কোনো বিশেষ ড্রাইভার লাগবে না — USB/Bluetooth স্ক্যানার কিবোর্ডের মতোই কাজ করে।

# প্রতিদিন যেভাবে চালাবেন

### বিক্রি করা (POS পেজ)

1. পণ্যে ক্লিক করুন **অথবা** বারকোড স্ক্যান করুন
2. **Customer Phone** ঘরে নাম্বার দিন
   - পুরনো কাস্টমার হলে নাম/পয়েন্ট/tier দেখাবে
   - নতুন হলে অটো মেম্বার হয়ে যাবে
3. **Keypad** দিয়ে টাকা বসান — বা **Exact / 500 / 1000 / 2000** চাপুন
4. বড় করে দেখাবে **কত টাকা ফেরত দিতে হবে**
5. **Checkout** চাপুন → সেল সেভ + স্টক কম + পয়েন্ট জমা + WhatsApp রিসিট

### অটোমেশন পেজ

| বাটন | কাজ |
|---|---|
| আজকের রিপোর্ট পাঠাও | বিক্রি/ক্যাশ/খরচ/বকেয়া → আপনার WhatsApp |
| স্টক কম রিপোর্ট | কোন মাল শেষ হচ্ছে |
| Remind | বকেয়া কাস্টমারকে ভদ্র রিমাইন্ডার |

# সমস্যা হলে

**এখনৈ Connect স্ক্রিন আসছে?**
→ `config.js` এ key ঠিকমতো বসেনি। F12 → Console দেখুন, লেখা আছে কিনা: `[config.js] Supabase config permanent set kora hoyeche`

**বারকোড কাজ করছে না?**
→ পণ্যে barcode সেভ করেছেন কিনা দেখুন; POS পেজে থাকতে হবে

**Login হচ্ছে কিন্তু Dashboard ফাঁকা?**
→ F12 → Console এর লাল লেখার screenshot পাঠান

**সব ঠিক আছে কিনা বুঝবেন কীভাবে?**
F12 → Console এ এই তিনটা লেখা থাকবে:
```
[config.js] Supabase config permanent set kora hoyeche
[automation.js] POS Automation add-on installed
[ui-upgrade.js] keypad + barcode + touch UI installed
```
